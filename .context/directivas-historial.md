# Historial de directivas superadas (EJEMPLO)

Cuando una orden nueva contradice o retira una directiva anterior, el texto superado se mueve aquí, textual, como una entrada `### H-nn` (fecha, motivo con su cita, lo vigente y el texto original). En `directivas.md` queda solo lo vigente con un puntero «historial H-nn». Este archivo no se carga al iniciar ni entra al mapa.
