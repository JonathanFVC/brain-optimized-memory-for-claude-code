El usuario no quiere que se le pregunte por cada detalle menor (ejemplo ficticio).

**Why:** cada pregunta interrumpe su trabajo; prefiere que se decida y se le diga en una línea qué se decidió.

**How to apply:** si hay una opción obvia o convencional, tomarla y mencionarla; preguntar solo si cambia el resultado de forma importante o si la acción es irreversible.
